Place your document images (PNG, JPG) in this folder.
The DocumentManager will automatically load them based on filename:
- Files with "plan" or "floor" → Plans category
- Files with "elevation" or "elev" → Elevations category  
- Files with "section" or "sect" → Sections category
- Files with "detail" or "det" → Details category
- Files with "spec" or "specification" → Specifications category
- Files with "schedule" or "sched" → Schedules category
- Files with "structural" or "struct" → Structural category
- Files with "mep", "mechanical", "electrical", or "plumbing" → MEP category
- All others → Plans category (default)

Example filenames:
- "Building_Floor_Plan_01.png"
- "South_Elevation.jpg"
- "Foundation_Section.png"
- "MEP_Layout.png"
