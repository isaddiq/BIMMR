□ USER ACTION REQUIRED
======================

Unity Editor Setup
------------------
□ Open Unity project
□ Locate "My Scripts" folder
□ Find FPSBenchmarker.cs (should be there)
□ Find ModuleManager.cs (should have changes)
□ Create empty GameObject or use existing manager object
□ Add FPSBenchmarker component
□ Assign ModuleManager reference in Inspector
□ Configure warmup/sample durations (defaults are good)
□ Check "Auto Benchmark On Load" if desired
□ Enable "Enable Debug Logs" for verbose output

Testing in Editor
-----------------
□ Enter Play mode
□ Load a BIM model via ModuleManager UI
□ Press 'B' key to start manual benchmark
□ Watch console for progress messages
□ Wait 75 seconds (15s warmup + 60s sampling)
□ Check console for completion message
□ Verify CSV path is logged
□ Exit Play mode
□ Navigate to path shown in console
□ Open fps_benchmark_results.csv
□ Verify header and data row exist

Quest 3 Build
-------------
□ Build Settings > Android platform
□ Set API Level to Android 10 or higher
□ Build and deploy to Quest 3
□ Put on headset and launch app
□ Load a BIM model
□ If auto-benchmark enabled, wait 75 seconds
□ Load another model to trigger another benchmark
□ Test for several models
□ Remove headset

Retrieve Results from Quest 3
------------------------------
□ Connect Quest to PC via USB-C cable
□ Put on headset briefly
□ Accept "Allow USB debugging" prompt
□ Accept "Allow file access" prompt
□ Remove headset
□ Open Windows File Explorer
□ Navigate to Quest 3 device
□ Browse to: Internal Storage > Android > data > [YourAppPackage] > files
□ Copy fps_benchmark_results.csv to PC
□ Open in Excel or Google Sheets

Analyze Results
---------------
□ Check timestamp column for run times
□ Verify modelId matches prefab names
□ Check runId increments correctly for same model
□ Verify sampleCount is ~3,600 (60 FPS * 60 seconds)
□ Compare meanFPS across different models
□ Check p1LowFPS for frame drops
□ Check notes column for any warnings
□ Plot FPS metrics to visualize performance
□ Check avgMemoryMB for memory usage patterns
