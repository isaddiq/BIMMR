KEY FEATURES IMPLEMENTED
-------------------------

✓ Event-based integration with ModuleManager
  - Uses OnModelLoaded/OnModelUnloaded events
  - No polling required
  - Automatic detection of model changes

✓ Measurement protocol (per requirements)
  - 15-second warm-up before sampling
  - 60-second FPS sampling window
  - Frame-by-frame sampling using Time.unscaledDeltaTime
  - Statistics: mean, median, p95, p99, 1% low

✓ Quest 3 compatible CSV output
  - Saves to Application.persistentDataPath
  - Appends to same file for multiple runs
  - Includes all requested columns plus memory usage
  - Includes notes field for warnings

✓ Control methods
  - StartBenchmarkForCurrentModel() - manual benchmark
  - StartAutoBenchmarkOnEveryLoad(bool) - automatic mode
  - CancelBenchmark() - safe cancellation

✓ Robust error handling
  - Detects model switches during benchmark
  - Validates model is fully loaded before starting
  - Logs detailed debug information
  - Safe cancellation at any point

✓ Memory tracking
  - Records GC.GetTotalMemory(false) during sampling
  - Calculates average managed memory in MB
  - Minimal performance impact

✓ Build-safe
  - No Editor-only APIs
  - Works in Quest APK builds
  - Uses unscaledDeltaTime (time-scale independent)


HOW IT WORKS
------------

Workflow:
  User loads model in ModuleManager
    ↓
  ModuleManager fires OnModelLoaded event
    ↓
  FPSBenchmarker receives event (if auto-benchmark enabled)
    ↓
  Validates model is active and loaded
    ↓
  STATE: WarmingUp (15 seconds)
    - Allows shaders to compile
    - Lets frame rate stabilize
    - Checks for model changes
    ↓
  STATE: Sampling (60 seconds)
    - Measures FPS every frame
    - Tracks memory every frame
    - Checks for model changes
    ↓
  Calculate statistics
    - Sort samples for percentiles
    - Compute mean, median
    - Calculate p1, p95, p99
    ↓
  Save to CSV with timestamp and metadata
    ↓
  STATE: Idle (ready for next benchmark)

ACCESSING RESULTS ON QUEST 3
-----------------------------

The CSV file is saved at:
  Application.persistentDataPath + "/fps_benchmark_results.csv"

On Quest 3, this resolves to:
  /storage/emulated/0/Android/data/[YourAppPackage]/files/fps_benchmark_results.csv

To retrieve:
1. Connect Quest to PC via USB
2. Enable file access on Quest (headset prompt)
3. Open Windows Explorer > Quest 3 > Internal Storage
4. Navigate to: Android/data/[YourAppPackage]/files/
5. Copy fps_benchmark_results.csv to PC

Exact path is logged in Unity console when benchmarks complete.

SUPPORT & CUSTOMIZATION
------------------------

To customize benchmark durations:
  - Edit warmupDuration field in Inspector (default: 15s)
  - Edit sampleDuration field in Inspector (default: 60s)

To add custom metrics:
  - Add sampling code in UpdateSampling() method
  - Add fields to BenchmarkStats struct
  - Update CSV header and row format

To integrate with other managers:
  - Implement IBimModelProvider interface
  - Fire OnModelLoaded/OnModelUnloaded events
  - Assign to benchmarker's moduleManagerReference
